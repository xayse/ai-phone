# Промптофон

Игра для 2–8 друзей в испорченный телефон с картинками нейросети.

**Играть:** https://xayse.github.io/ai-phone/

Каждый участник начинает свою цепочку. Он пишет идею, нейросеть рисует её, а следующий игрок описывает полученную картинку. Цепочки движутся одновременно. В финале ведущий открывает истории по очереди.

Создайте комнату, скопируйте приглашение и отправьте друзьям. Для входа достаточно ника. Основной генератор — FLUX.1 schnell в Cloudflare Workers AI, резервный — AI Horde. Компьютер владельца игры можно выключить. Скорость зависит от доступности генератора; при переходе на Horde возможна общая очередь. При ошибке ведущий может повторить запрос или пропустить картинку.

Сайт размещён на GitHub Pages, комнаты обслуживает Cloudflare Worker с Durable Objects. Русские описания переводятся через Workers AI, а после исчерпания его квоты — через текстовых исполнителей AI Horde. Исходный текст сохраняется для финала. Бесплатная квота Workers AI общая для перевода и генерации; на Workers Free при её исчерпании платные запросы не включаются. До следующего сброса квоты комната использует Horde для перевода и картинок. Ключ Horde для изображений хранится только в секрете Worker `HORDE_API_KEY`; резервный перевод использует публичный анонимный доступ и не требует нового ключа. Уже принятые задания перевода и картинок сохраняются при обновлении сервера.

Локальный запуск: `node server/local.mjs` (Node.js 22+), затем http://localhost:4173. Без привязки Workers AI русский текст переводится через Horde; для перевода и картинок используется общая очередь добровольных исполнителей.

Проверки: `node --test server/worker.test.mjs`. Настройки публикации, ограничения и устройство проекта описаны в [SETUP.txt](SETUP.txt).
