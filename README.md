# Промптофон

Игра для 2–8 друзей в испорченный телефон с картинками AI Horde.

**Играть:** https://xayse.github.io/ai-phone/

Каждый участник начинает свою цепочку. Он пишет идею, AI Horde рисует её, а следующий игрок описывает полученную картинку. Цепочки движутся одновременно. В финале ведущий открывает истории по очереди.

Создайте комнату, скопируйте приглашение и отправьте друзьям. Для входа достаточно ника. Генерация идёт на компьютерах добровольцев AI Horde; компьютер владельца игры можно выключить. Ожидание зависит от общей очереди Horde. При ошибке ведущий может повторить запрос или пропустить картинку.

Сайт размещён на GitHub Pages, комнаты обслуживает Cloudflare Worker с Durable Objects. Русские описания переводятся через Workers AI; исходный текст сохраняется для финала. Ключ Horde хранится только в секрете Worker `HORDE_API_KEY` и не входит в этот репозиторий.

Локальный запуск: `node server/local.mjs` (Node.js 22+), затем http://localhost:4173. Локально вводите идеи по-английски: привязка Workers AI доступна в Cloudflare.

Проверки: `node --test server/worker.test.mjs`. Настройки публикации, ограничения и устройство проекта описаны в [SETUP.txt](SETUP.txt).
