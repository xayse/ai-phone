ПРОМПТОФОН

Игра для 2–8 друзей. Каждый начинает свою цепочку: текст → картинка нейросети → описание следующего игрока → новая картинка. Ведущий открывает готовые цепочки по очереди.

Размещение
1. GitHub Pages публикует папку site через .github/workflows/pages.yml.
2. Cloudflare Workers запускает server/worker.mjs. Настройки и SQLite Durable Objects объявлены в wrangler.jsonc.
3. При доступном AI binding основной генератор — Cloudflare Workers AI FLUX.1 schnell. Если генерация недоступна или бесплатная квота исчерпана, запрос переходит в AI Horde. IMAGE_PROVIDER=horde в переменных Worker принудительно выбирает прежний генератор. Без AI binding (например локально) работает Horde. Уже принятые задания Horde продолжаются без отмены при обновлении.
4. Для Horde без ключа используется бесплатный анонимный режим. При наличии своего ключа добавьте HORDE_API_KEY как Secret в настройках Worker. Не добавляйте ключ в публичные файлы, GitHub Variables или site/config.js.
5. Cloudflare AI переводит русские описания на английский перед генерацией. Исходные описания сохраняются для финального просмотра. Бесплатные 10 000 Neurons в день на аккаунт расходуются и на перевод, и на картинки. Используйте Workers Free: превышение квоты отклоняется без автоматического перехода на платный тариф. Если недоступен сам перевод, ведущий получит понятную ошибку для повтора.

GitHub Pages
В Settings → Pages выберите Source: GitHub Actions.
В Settings → Secrets and variables → Actions → Variables добавьте PUBLIC_API_BASE: адрес сервера без пути, например https://ai-phone-api.example.workers.dev.
Затем запустите Publish game to GitHub Pages во вкладке Actions.

Cloudflare
Создайте Worker из этого репозитория. Имя проекта: ai-phone-api.
Build command: node --test server/worker.test.mjs
Deploy command: npx wrangler deploy
В ALLOWED_ORIGIN должен быть origin сайта (например https://xayse.github.io), без /ai-phone/.
Конфигурация сама объявляет ROOMS и AI, а также первоначальную SQLite-миграцию.
Используйте Workers Free. Скорость генерации зависит от доступности провайдера. В резервном Horde она зависит от загрузки добровольных исполнителей, поэтому фиксированное время ответа не гарантируется.

Локальный запуск (Node.js 22 или новее)
node server/local.mjs
Откройте http://localhost:4173.
Локальные данные сохраняются в .local-data; эта папка исключена из Git.
Локально нет Cloudflare AI binding: для точного рисунка вводите описания по-английски.

Проверки
node --test server/worker.test.mjs
node --check site/app.js

Что предусмотрено
— отдельная цепочка на каждого игрока;
— скрытие прежних промптов и чужих картинок до финала;
— восстановление участника в том же браузере после обновления страницы;
— таймер ответа отдельно от ожидания картинок;
— повтор ошибок и пропуск генерации ведущим;
— приватная выдача изображений участникам комнаты;
— автоматическое закрытие неактивной комнаты через 24 часа.

Секреты и данные партий не входят в исходный код. Для новой партии после финала ведущий нажимает «Ещё одну игру».
